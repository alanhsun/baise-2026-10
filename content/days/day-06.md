# D6 · 10月6日 周二｜G2955南宁到虎门

**当天目标：从南宁站乘G2955到虎门，再打车回东莞南城。** 当前公开参考13:58—17:27；车票尚未购买，最终时刻、站名和价格只认12306票面。

## 当天照着走

**以下按计划G2955南宁站13:58→虎门17:27编排，车票仍以用户后续确认和12306订单为准。** 购票目标为9月22日15:15，出发前仍未买到时应先落实可用返程车次，再重算整天时间；不能把计划车次当成已出票。

### 第1步｜起床先看订单，08:00左右吃早餐

打开订单核对日期、车次、出发站、到达站、三位乘车人和席位。重点看出发站写的是**南宁**还是**南宁东**：本攻略酒店和送站按南宁站安排，如果实际订单是南宁东，必须重新计算车程与出门时间，不照抄12:00出门。

08:00—09:00正常吃早餐，确认酒店早餐是否含孩子；不含时直接在酒店附近解决。早餐后回房整理，不安排离开酒店片区的景点。

### 第2步｜09:00—11:00：收拾行李，确定进站路线

成人一人负责证件和孩子，另一人负责箱包、车票屏幕与叫车。大箱装好后查床头插座、浴室、衣柜和充电设备，把车上要用的水、点心、纸巾、药、外套放日用包。

向前台确认到**南宁站旅客进站口**的实际步行路线。只有无明显绕路、天气适合、拖箱方便时才步行；否则正规平台短程叫车。09:00—11:00的空余只用于房间休息或附近补给，11:00前回到房间。

### 第3步｜11:00—12:00：退房，提前吃一顿热午餐

11:00左右办理退房。酒店有餐厅或紧邻餐饮就原地吃；需要走远时，优先在酒店或车站附近找可以快速出餐的店。预计上菜超过20分钟就换粉面／简餐，不在离店前排网红店。

点清淡主食、鸡蛋／豆腐、青菜和一份肉菜，孩子先吃。11:45开始结账、上洗手间，12:00前结束用餐；另带独立包装点心到车上，不带容易洒漏的汤粉。

### 第4步｜12:00—12:30：去南宁站，不把近站当作免缓冲

12:00左右从酒店片区前往南宁站，目标12:30前进入站房。遇下雨、叫车等待或人流绕行时立刻出发，不再买东西。下车先取齐后备厢行李再带孩子离开，所有人到安全处集合后进入车站。

到站先确认大屏上的G2955和检票口，再安检、找候车区域。12:30到站意味着预留约88分钟，包含安检、找检票口、洗手间和国庆人流；这段是缓冲，不是必须站着排队88分钟。

### 第5步｜候车和上车：先在检票口附近安顿

确认检票口后，一人带孩子上洗手间，另一人守行李和看屏；之后换另一位成人处理个人事项。需要补水就在附近完成，手机保留足够电量，车票截图离线可看。

检票开始后按车厢指示排队，全家一起过闸。上车先让孩子按票入座，再放大箱、外套和日用包。13:58参考出发后以休息为主，15:00—15:30可吃一份小点心，不用代替晚餐。

### 第6步｜17:10起整理，虎门站出站后再叫车

距虎门到站约15—20分钟收充电线和零食，检查小桌板、座位下、椅背袋和行李架。先确认到站广播是虎门，再取大箱；车停稳后一起下车。

出站后先上洗手间、确认正规上客区和平台要求的集合点，再下单回南城。给司机发送明确上客点，核对车牌后上车；不要一人带孩子在路边等、另一人到处找车。

### 第7步｜约18:30—19:00到家，晚餐就近

虎门到南城按国庆晚高峰45—75分钟估算，实际到家时间受出站、排队和交通影响。车上看实时导航再决定到家吃饭或在家附近吃清淡热饭，不为固定餐厅预约赶路。下车前清空后备厢，确认三人的证件和电子设备齐全。

## 返程发生变化时

| 情况 | 直接这样处理 |
| --- | --- |
| 实际买到的车次或发车站不同 | 根据票面重新计算到站、车程与午餐时间，不能只改车次名字 |
| 午餐上菜慢 | 停止加菜，结账或打包，优先保留12:30到站目标 |
| 车次晚点但未通知停止检票 | 仍按原计划到站，以铁路通知安排候车，不自行晚到 |
| 虎门网约车排队很久 | 同时了解正规出租车队列，选择等候更可控的一种，取消未使用订单 |

- 虎门出站后全家一起到正规上客区，再叫车回南城。
