# D6 · 10月6日 周二｜已购D593，南宁东到广州南

**当天目标：南宁站附近酒店→打车到南宁东站→已购D593到广州南→步行换乘番禺城际站→西平西→打车回南城。** D593已由用户确认购买；广州南之后的城际尚未确定车次或购买。住宿继续选南宁站附近，今早需要跨城区送站。

**时刻口径：**公开页面参考D593 **11:28南宁东出发、14:13—14:14广州南到达**，不同页面相差1分钟，以下按14:14安排。用户尚未提供票面时刻、席别及实付金额；执行以10月6日私人订单为准。若票面发车时间变化，酒店出门时间按“发车前约2小时45分”重新倒推。

## 当天照着走

### 第1步｜07:30吃早餐，再核对一次“南宁东”

起床先看12306订单和铁路通知，确认10月6日、D593、南宁东→广州南、三位乘车人。把证件、水、纸巾、外套、充电设备和路餐放随身包，大箱只装途中不需要的物品。

07:30左右在酒店吃早餐；不含早就选附近能快速出餐的粉面或简餐，08:00前吃完。不再安排南宁游览或排队买伴手礼。前晚备好的路餐检查保存情况，易腐食物不在常温下过夜。

### 第2步｜08:00整理退房，08:45前上车

一位成人负责孩子、证件和订单，另一位负责箱包、退房与叫车。检查床头、插座、浴室、衣柜和冰箱，08:30前到大堂。目的地完整写成**南宁东站旅客进站口**，请司机确认当天可用的送客入口。

南宁站周边酒店到南宁东站按45—60分钟门到门规划，三人一车暂留40—80元，均不是实时导航或报价。前晚先查路线并预约，早晨再看路况；平台预计车程超过60分钟就提前出门。发车前约2小时45分出门包含候车缓冲，不代表市区开车需要这么久。

### 第3步｜目标09:45到南宁东，安检后直接找检票口

下车前取齐后备厢行李，全家一起到安全处。看站名确为南宁东，再进站安检；按大屏查D593检票口，避免只凭截图寻找可能调整的检票口。

安顿后轮流上洗手间、补水、检查手机电量。还没准备午餐时，可在候车区购买可携带的正规简餐；不因买饭远离候车区域或错过检票。09:45到站距参考发车约103分钟，涵盖国庆人流与孩子临时需求。

### 第4步｜11:28参考发车，午餐放到车上

开始检票后按车厢号走，全家一起过闸。上车先让孩子坐好，再放大箱；午餐、纸巾和水放随身包。席别与座位按已购订单，不推定二等座或连座。

12:00左右吃午餐：路餐可选当天购买的饭团、面包、水果等，或按实际供应购买列车餐，三人暂留100—180元。孩子先吃，避免容易洒漏的食物。13:50左右收拾充电线、垃圾和外套，听清“广州南”到站广播再准备下车。

### 第5步｜约14:14到广州南，跟“番禺站／广东城际”指示换乘

**D593到达广州南站；下一段从番禺城际站出发。** 番禺城际站位于广州南地下空间，按现场连接通道导向步行换乘，不需要打车去另一个城区的“番禺”。先按实际出口和广东城际指示走，不预先承诺固定闸口、免安检或无需出站。

找不到指示就问工作人员：“去番禺城际站，坐到西平西，怎么走？”留出上洗手间、步行、可能的安检与候车时间。建筑相邻不等于5分钟能换乘，不在广州南安排正餐或购物。

### 第6步｜选择15:15以后直达西平西的城际，优先留90分钟

在官方售票渠道查**10月6日番禺→西平西直达**，目的地是“西平西”，不要误选“东莞西”。15:15只是D593参考到达后约60分钟的选班下限，并非已查到的指定日期车次；带娃带箱更建议选15:45左右或更晚，尽量留90分钟。

现有非出行日公开页面显示该区间有直达城际，但10月6日车次、停站、票价及票种规则仍需实际查询。三人暂留80—100元，运行时间先按约40—65分钟规划。按所购票种完成实名查验及进站，不默认不同票种间可随意换车。

D593晚点或换乘人流超预期时，按票种办理可用的改签或重新选择后续班次，不带孩子奔跑赶车。只选明确停靠西平西的车，现场工作人员指引优先。

### 第7步｜西平西出站再叫车，到南城后晚餐

出站先确认正规上客区，再叫车回南城，按20—40分钟、20—50元预留，实际以家址和实时路况为准。若顺利接上15点多的城际，约16:30—17:30到家可作作息参考，不作承诺。

成人一人带孩子、一人清点箱包，全家到同一上客点后联系司机。下车时取齐后备厢物品。晚餐在家或家附近吃清淡热饭，不为固定餐厅预约赶路。

## 返程发生变化时

| 情况 | 直接这样处理 |
| --- | --- |
| 票面时刻与公开参考不同 | 按票面倒推送站、候车和广东段接续，保留至少60—90分钟换乘余量 |
| 酒店门口难叫车或拥堵 | 前晚预约并确认上客点；当天尽早请前台协助正规出租车，车程增长就提前出门 |
| 不慎叫成“南宁站” | 上车前立即改为南宁东站；10月5日到达站与10月6日出发站不同 |
| D593晚点 | 按铁路通知候车；广州南接续选择更晚的直达城际，不压缩步行时间 |
| 城际临时停运或当天无可用接续 | 广州南正规网约车直达南城作兜底；现场核价，额外费用从备用金核算，不与城际方案重复相加 |
