# D4 · 10月4日 周日｜鹅泉慢游，回靖西住宿

**当天目标：只游鹅泉，13:30坐预约车回酒店，下午休息。** 预计步行2—4公里，可随时缩短；今晚仍住已订尚客优，第2晚。

## 推荐路线与必看

1. **正式入口**：确认洗手间、开放路线、门票和竹筏是否分别收费。
2. **十五孔桥两岸**：从桥侧拍桥孔、倒影和远山；桥上只通行，不久站。
3. **泉池、水草和鱼群**：沿连续岸线慢走，不跨护栏、不踩踏石冒险。
4. **鹅字碑／泉边碑刻**：读现场说明，不触摸或攀靠。
5. **田园步道＋一级观景台**：一次看全泉池、古桥、村落和峰林；二级台不作为必达。
6. **原路回出口午餐**：竹筏放在午餐后决定，不挤占上午主线。

**竹筏只在以下条件全部满足时选择：**正规售票、三人总价和时长清楚、儿童救生衣合身、上下筏有人协助、天气稳定、排队不超过20分钟。

## 当天照着走

鹅泉这一天以泉水、古桥和田园为主，上午完成核心游览，下午留给休息和翌日火车准备。表中时间是建议节奏；实际桥、泉池与检票口的先后，以当日入口和导览图调整，避免为凑顺序来回绕路。

### 第1步｜07:15—09:00：吃早餐，确认往返车再出门

早餐后带水、点心、雨具、帽子和充电宝，大箱留在酒店。07:45左右在大堂联系司机，复述“08:00酒店接、鹅泉正式游客入口、13:30接回同一酒店”，确认上客点和往返价格。

车程按含候车、进村和节假日排队约1小时安排。到景区先拍下返程停车点并发给司机，再上洗手间、看导览图。门票和竹筏分别问价，儿童票按当天规则办理，不在村口购买无凭证的带入套餐。

### 第2步｜09:00—09:30：十五孔桥与桥侧倒影

先从两岸允许停留的步道看整座桥，找“桥孔＋水面＋远山”的构图；桥上人多时从侧面拍，不站在桥中阻挡通行。把全家照放在这一段完成，后面就不用反复找拍照位置。

可以让孩子数桥孔、找倒影，停留15—25分钟足够。路面湿滑或桥面拥堵时只看两岸视角，过桥按现场人流指示走。十五孔桥是鹅泉的代表景观，竹筏只是可选体验。[景观参考：广西气象专题](https://gx.weather.com.cn/zt/3477559.shtml)

### 第3步｜09:30—10:15：泉池、水草、鱼群和碑刻

沿开放岸线走到能看清水草和鱼群的位置，先停下观察水色，再继续走。教孩子看“水下植物随水流摆动”，比沿湖快速走一圈更容易留下印象；不为拍透明水面越过护栏或踩湿石头。

顺路看鹅字碑、泉边碑刻或杨媪传说相关说明，以现场标识为准。把故事当作当地传说讲给孩子听，不把每处碑刻都变成必须到访的点。10:15左右找有座位的地方坐休、喝水、上洗手间。

### 第4步｜10:40—11:30：田园步道，体力好才上一级观景台

先看当天田园和村落，国庆稻田是否收割取决于现场农时。只在步道上拍照，不进入农田。孩子愿意走、台阶干燥且人流顺畅时，按景区指示上较低一级观景点；不确定上下需要多久，先问工作人员。

以10—15分钟单向爬升作为家庭尝试上限：孩子气喘、说累、台阶湿滑或迟迟到不了平台就折返。到了平台拍一张泉池、桥、村落与峰林的整体照片，短休后下山；不再追更高一级机位。

11:00前联系午餐店确认散客桌和出菜时间。11:15左右停止往远处走，向餐厅方向移动，11:30开餐。

### 第5步｜11:30—12:45：午饭，不为餐厅跨出很远

先尝试本日美食里的山水人家食庄，地图定位必须确认是鹅泉店。满座且等位超过20分钟，直接改景区正式经营区有座餐馆。点鸡蛋／豆腐、青菜、少量肉菜和米饭，辣椒分开；选择能在30分钟左右出菜的菜式。

若餐厅在检票区外，离开前先问能否再次入园；没有确认二次入园资格，就把午餐后的竹筏取消，吃完直接回接车点。不要为了竹筏再买一次门票。12:30联系司机，复核13:30接回位置。

### 第6步｜12:45—13:30：竹筏或补看泉景，然后回车

只有天气稳定、正规售票、儿童救生衣合身、上下筏有人协助，而且项目能在13:00左右结束、足够走回上客点，才选择竹筏；排队超过20分钟直接放弃。实际航程或回程码头不清楚时，也不购买。

不坐筏就在出口方向的岸边坐一会儿或补拍泉景。13:00开始回停车点，途中上洗手间，13:15—13:30与司机会合。若上午已经看够、孩子疲劳，可联系司机协商提前返回，以司机确认时间为准。

### 第7步｜14:30以后：回房午休，准备K9304

回同一酒店后洗澡、午睡或安静休息，不再加旧州、峡谷等景点。17:00左右整理行李，把明早证件、早餐和常用物品单独放好，其余入箱。

晚餐按本日美食选择，18:00—19:00吃完较合适。20:00前打开K9304私人订单核对日期、站名、发车时刻和席位，并与送站司机确认次日时间。酒店若不能提供早早餐，当晚买好面包、常温奶、水果和水。

## 体力或天气变化时

| 情况 | 保留什么、删掉什么 |
| --- | --- |
| 孩子不愿爬台阶 | 保留桥、泉池和田园平路，取消观景台 |
| 泉边人多 | 先看较空的一侧，稍后顺路补桥侧，不反复折返 |
| 小雨、台阶湿滑 | 走短平路，取消登高和竹筏，午餐后返回 |
| 雷电、强降雨或关闭 | 取消室外游览，回酒店休息 |
| 午餐拖延到13:00 | 取消所有体验，吃完去上客点，必要时提前联系司机协调 |

## 看点与现场提醒

- 到达先买正式门票，再决定竹筏；不接受村口“坐筏带进去”等无凭证方案。
- 10月稻田颜色取决于收割进度，不把春季花海当作国庆预期。
- 普通小雨缩短步行；雷电、强降雨或临时关闭时取消室外游览。
- 13:30必须保留回程。回酒店后完成大部分收拾，并确认酒店能否提前早餐或打包。
